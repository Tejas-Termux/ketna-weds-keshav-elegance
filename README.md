Overall Design Style

The website should resemble a luxury Indian Hindu wedding invitation, inspired by premium wedding invitation microsites. The experience should feel emotional, graceful, and festive, with subtle traditional motifs, royal color accents, elegant typography, and tasteful animations. Avoid clutter, flashy effects, or a generic template appearance. The final result should look handcrafted and memorable.
